    The document must include ALL of the following sections, in this order:

    ## When to Use This Guide
    A 2–3 sentence intro: use this guide when `uv run python pipeline/acquire_google.py` or `uv run python pipeline/acquire_pictime.py` fails, and you need to download photos manually to continue the pipeline.

    ## Source Folder Structure
    A table or list showing the required output folder layout:
      sources/photographer_a/   — Google Photos album 1 (Photographer A)
      sources/photographer_b/   — Google Photos album 2 (Photographer B)
      sources/photographer_c/   — Google Photos album 3 (Photographer C, film scans)
      sources/pic_time/         — pic-time gallery photos

    Explain that these folder names are read by subsequent pipeline steps via pipeline/config.yaml. Do not rename them.

    ## Google Photos Manual Download

    Step-by-step instructions to manually download each of the 3 albums:
    1. Open each album URL (from the `album_url` fields in pipeline/config.yaml — substitute the real URLs once known).
    2. Select all photos in the album: click the first photo, then Shift+click the last, or use "Select all" if available.
    3. Click the download button (cloud icon with down arrow) to download a ZIP.
    4. Extract the ZIP contents into the corresponding folder: sources/photographer_a/, sources/photographer_b/, or sources/photographer_c/. Match album to folder per the label in pipeline/config.yaml.
    5. Verify: each folder should contain .jpg or .JPG files directly (not nested in subfolders). If Google Photos creates subfolders by date, move all .jpg files to the folder root.

    Note: Google Photos shared albums do not require a Google account to download if the link has "Anyone with the link" sharing.

    ## pic-time Manual Download

    Step-by-step instructions to manually download from the pic-time gallery:
    1. Open https://justsmile.pic-time.com/gallery in a browser.
    2. Look for a download button or "Download all" option in the gallery UI. pic-time galleries typically have a bulk download option in the top toolbar.
    3. Download the ZIP and extract all images into sources/pic_time/.
    4. If no bulk download is available: right-click each image → Save image → save to sources/pic_time/. (Note the image count from the gallery page to verify completeness.)

    Alternative: Use `wget` to download individual images: `wget -P sources/pic_time/ <image_url>` for each image URL visible in browser DevTools → Network tab → filter by image type.

    ## Verification After Manual Download

    Commands to verify the folder contents are populated and the pipeline can proceed:
    ```bash
    find sources/ -name "*.jpg" -o -name "*.JPG" | wc -l
    # Expected: total count across all folders should match the number of photos from all sources
    ls sources/photographer_a/ | wc -l
    ls sources/photographer_b/ | wc -l
    ls sources/photographer_c/ | wc -l
    ls sources/pic_time/ | wc -l
    ```

    Include a note: once photos are in the correct folders, the rest of the pipeline (Phase 2 onwards) runs identically whether photos were downloaded automatically or manually.

    Use clear heading hierarchy (## and ### only, no ####). Write in plain English, not imperative bullet lists — numbered steps for sequential actions, bullet points for options/alternatives.
