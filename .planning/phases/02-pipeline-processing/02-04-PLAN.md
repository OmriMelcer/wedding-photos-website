<objective>
Build `pipeline/cluster.py` — Stage 3 of Phase 2. Combine catalog.json + embeddings.npy + config.yaml time windows into the upload-ready `pipeline/output/metadata.json`. Digital photos get EXIF-driven cluster labels (confidence=1.0); film photos get KNN-against-centroid labels with a cosine-similarity confidence score; photos below the configured threshold are flagged in `pipeline/output/low_confidence.txt`.

Purpose: This is the heart of Phase 2 — it implements PIPE-04 (time-window cluster assignment), PIPE-05 (centroid + KNN for film), and PIPE-06 (confidence scoring + human review list). After this plan completes, metadata.json contains every field the Phase 4 React site needs except the R2 URLs (filled in by Phase 3 upload.py).

Output: pipeline/cluster.py + pipeline/output/metadata.json + pipeline/output/low_confidence.txt.
</objective>
