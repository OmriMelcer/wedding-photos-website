<objective>
Wire the yarl Zoom plugin into the existing `LightboxWrapper` so guests get pinch-to-zoom (ZOOM-01), scroll-wheel zoom (ZOOM-02), and drag-to-pan (ZOOM-03), with mobile-safe configuration — all without adding any new npm dependency.

Purpose: Unlock all three v1.3 requirements through a single-file change. The Zoom plugin ships inside the already-installed `yet-another-react-lightbox@^3.32.0`. The critical landmines are (1) `maxZoomPixelRatio` defaulting to 1 silently disables zoom on every retina/mobile device, and (2) iOS swipe-block after fast pinch-out requires `pinchZoomV4: true`.

Note: Hebrew tooltip labels for Zoom in/out are explicitly deferred (REQUIREMENTS.md "Out of Scope") — do not add "Zoom in"/"Zoom out" label keys.

Output: Modified `Lightbox.jsx` with Zoom plugin import, plugin registration, full zoom config — plus matching test assertions in `Lightbox.test.jsx`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser DOM ↔ yarl plugin | Guest-controlled wheel/touch/mouse events feed into the third-party Zoom plugin running in our React tree. |
| npm dependency tree ↔ build | `yet-another-react-lightbox/plugins/zoom` is an additional entry-point import; resolved at build time from the same already-installed package. |
| Public R2 image URLs ↔ Zoom rendering | The Zoom plugin renders images already served from public R2; no new origin or auth surface introduced. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-01 | Tampering | Zoom plugin sub-path import (`yet-another-react-lightbox/plugins/zoom`) | mitigate | Reuses already-vetted `yet-another-react-lightbox@^3.32.0` (in package.json). No new package added — no supply-chain delta. Build step in Task 2 verify confirms the import resolves against the installed lockfile entry. |
| T-10-02 | Denial of Service | Zoom rendering at `maxZoomPixelRatio: 3` on full-resolution R2 images | accept | Images are web-resized by the pipeline before upload; the largest dimension is well under what a modern browser can scale 3x in canvas. No new bandwidth — same R2 image already loaded for non-zoom display. |
| T-10-03 | Information Disclosure | Zoom plugin event handlers leaking pointer/touch data | accept | yarl Zoom plugin processes events locally in the browser; no telemetry, no network calls from the plugin. Plugin source is bundled, not loaded from a CDN. |
| T-10-SC | Tampering | npm installs | accept | No `npm install` performed in this phase. Zoom plugin ships inside the existing `yet-another-react-lightbox@^3.32.0` entry already in `site/package.json`. No package-legitimacy audit required — no new package is being added. |
</threat_model>
