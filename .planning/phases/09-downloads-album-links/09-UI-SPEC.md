## Component Inventory

### New: TopBar

- **Location:** `site/src/components/TopBar.jsx` (new file), rendered in `App.jsx` above `<Filters>`
- **Layout:** Full-width, `bg-stone-100 border-b border-stone-200 px-4 sm:px-8 lg:px-12 py-3`
- **Content:** 4 album link buttons arranged in a flex row, `gap-2`, aligned to the inline-start (right side in RTL = visual right)
- **RTL note:** "left side of the top bar" in the requirement means the inline-start side. In RTL (`dir="rtl"`) inline-start is the visual right. Use `justify-end` (flex default pushes to end) OR `justify-start` with RTL direction. Decision: use `flex gap-2` without explicit justification — buttons naturally flow from inline-start in RTL. Do NOT use `float:left` or absolute positioning.
- **Each album link button:**
  - Renders as `<a href={url} target="_blank" rel="noopener noreferrer">`
  - Uses shadcn `Button` with `variant="outline"` and `size="sm"` — consistent with existing `Button` usage in ErrorState
  - Label: Hebrew short name (e.g. "אביר סולטן", "ענבל זלדין", "מגנטים", "Pic-Time") — exact labels defined in `config.js`
  - Icon: `ExternalLink` from lucide-react, 14px, placed at `data-icon="inline-start"` (logical, appears at visual left of label in LTR, visual right in RTL — acceptable, consistent with lucide icon placement)
  - Touch target: `min-h-[44px]` (override via `className` on Button)
  - Hover: `hover:bg-stone-300` (matches inactive chip hover)
  - No active/pressed state needed (these are navigation links, not toggle controls)

### Modified: PhotoCard

- **Addition:** Download icon overlay at `absolute bottom-0 end-0 m-1.5` (logical — mirrors photographer badge at `bottom-0 start-0`)
- **Trigger:** `group-hover:opacity-100` — same pattern as photographer credit badge
- **Appearance:** `bg-black/50 text-white rounded p-1.5 opacity-0 group-hover:opacity-100 transition-opacity duration-200`
- **Icon:** `Download` from lucide-react, `size-4` (16px)
- **Interaction:** `<a>` tag with `href={photo.r2_url}` and `download={photo.filename}` — native browser download, no JS required
- **Accessibility:** `aria-label` in Hebrew: `"הורד תמונה"`
- **Click behavior:** Must NOT trigger lightbox open. Use `e.stopPropagation()` on the anchor's click handler.
- **Positioning note:** In RTL, `end-0` resolves to visual left (inline-end = left edge in RTL). Both badges (photographer at `start-0` = visual right, download at `end-0` = visual left) appear in opposite bottom corners — intentional visual separation.

### Modified: Lightbox (LightboxWrapper)

- **Addition:** yarl Download plugin
- **Import:** `import Download from 'yet-another-react-lightbox/plugins/download'`
- **Plugin config:** Pass `download` prop to `YarlLightbox` with `plugins={[Download]}`
- **Slide shape:** Each slide must include `downloadUrl: photo.r2_url` and `downloadFilename: photo.filename`
- **Updated yarlSlides map:** `{ src: photo.r2_url, alt: photo.id, downloadUrl: photo.r2_url, downloadFilename: photo.filename }`
- **Toolbar position:** yarl Download plugin appends a download button to the lightbox toolbar automatically — no manual positioning needed
- **RTL:** Lightbox already has `portal={{ container: { dir: 'rtl' } }}` — toolbar renders correctly in RTL

### Modified: config.js

- **Addition:** `ALBUM_LINKS` array export
- **Shape:** `[{ label: string, url: string }]` — 4 entries (3 Google Photos, 1 pic-time)
- **Placeholder values at spec time:** URLs are not yet known; executor inserts `'#'` placeholders with a comment marking them for replacement
- **Export name:** `ALBUM_LINKS` (screaming snake case, consistent with `PHASE_LABELS`, `PHASE_ORDER`, `PHOTOGRAPHER_NAMES`)

## RTL Contract

All new elements follow existing RTL conventions established in the codebase:

1. **Logical properties only.** Use `start-*`/`end-*`, `ms-*`/`me-*`, `ps-*`/`pe-*` — never `left-*`/`right-*`/`ml-*`/`mr-*`/`pl-*`/`pr-*`.
2. **TopBar button flow.** Album link buttons use `flex gap-2`. In RTL, flex items flow from inline-start (visual right). This satisfies LINK-01 "placed on the left side" which means inline-start in RTL context.
3. **Download icon on PhotoCard.** Position `bottom-0 end-0` — inline-end = visual left in RTL. Photographer badge at `bottom-0 start-0` = visual right. They occupy opposite corners.
4. **Icon placement inside buttons.** lucide icons passed via `data-icon="inline-start"` convention used in shadcn button; icon renders before label text in reading direction.
5. **yarl RTL.** Already handled by existing `portal={{ container: { dir: 'rtl' } }}`.

## Accessibility Requirements

- All interactive elements must meet WCAG 2.1 AA touch target: `min-h-[44px]` minimum
- Album link buttons: `target="_blank"` requires `rel="noopener noreferrer"` (security + accessibility)
- Download anchor on PhotoCard: `aria-label="הורד תמונה"` (icon-only, no visible text)
- TopBar nav element: `<nav aria-label="אלבומי המקור">`
- External link icon: `aria-hidden="true"` on the lucide `ExternalLink` icon (label text communicates destination)
- Download icon on PhotoCard: `aria-hidden="true"` on lucide `Download` icon (aria-label on anchor handles it)
