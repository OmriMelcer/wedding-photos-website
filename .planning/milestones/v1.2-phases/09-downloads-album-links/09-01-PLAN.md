|----------|-------------|
| guest browser → external album (Google Photos, Pic-Time) | New outbound links open in new tabs; target sites are third-party but already publicly accessible |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-01 | Tampering | window.opener reverse-tabnabbing | mitigate | All album link anchors set `rel="noopener noreferrer"` per UI-SPEC §Accessibility; verified by grep in acceptance criteria |
| T-09-02 | Information Disclosure | Album URLs in static config | accept | Album URLs are intentionally shared with all guests; placing them in config.js is the same trust level as the rest of the static bundle (no PII, share-link auth is governed by the album provider) |
| T-09-03 | Tampering | XSS via ALBUM_LINKS label/url | mitigate | Labels and URLs are bundled at build time from source-controlled config.js (no runtime input); React escapes label text by default; `href` is a literal string from config, never user input |
</threat_model>
