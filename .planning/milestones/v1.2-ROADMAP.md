# Milestone v1.2: Downloads & Album Links

**Status:** ✅ SHIPPED 2026-05-23
**Phases:** 9
**Total Plans:** 3

## Overview

Guests can now download individual photos and jump directly to the original source albums. Downloads are proxied through a Cloudflare Worker `/api/download` route (bypasses the R2 CORS restriction on cross-origin `download` attribute). Four Hebrew top-bar buttons link to the 3 Google Photos albums + pic-time gallery. All album URLs live in `site/src/config.js` for zero-touch updates.

## Milestone Summary

**Key Decisions:**

- Download proxied through Worker `/api/download` (not direct R2 fetch) — browser `download` attribute silently ignored for cross-origin URLs; Worker adds `Content-Disposition: attachment`
- Used modern yarl `download: { url, filename }` object form (not deprecated `downloadUrl`/`downloadFilename` string properties)
- Labels: אביר סולטן, ענבל זלדין, מגנטים, פילם (Hebrew throughout)
- Download icon at `bottom-0 end-0` (logical CSS, RTL-safe); badge at `bottom-0 start-0`

**Issues Resolved:**

- Cross-origin download attribute restriction (R2 → Worker proxy)
- RTL download icon placement (logical CSS properties)

**Issues Deferred:**

- Face recognition: FACE-01..04 still in v2 scope

**Technical Debt Incurred:**

None — this was a purely additive frontend + Worker feature.
