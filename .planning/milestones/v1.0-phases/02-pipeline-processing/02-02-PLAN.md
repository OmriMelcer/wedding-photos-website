<objective>
Build `pipeline/ingest.py` — Stage 1 of the Phase 2 processing pipeline. Walk every source folder declared in `pipeline/config.yaml sources.local_sources`, extract EXIF timestamps with timezone normalization, assign photographer labels, and emit `pipeline/output/catalog.json`.

Purpose: catalog.json is the shared input for embed.py (which appends embeddings) and cluster.py (which assigns event clusters). Getting EXIF timezone handling right here prevents every downstream cluster misassignment — RESEARCH.md Pitfall #1 (the `+00:00`-means-local-not-UTC trap) is the single most consequential bug in this phase.

Output: pipeline/ingest.py implementing the script skeleton + EXIF normalization + photographer tagging; running it produces pipeline/output/catalog.json with one entry per source image.
</objective>
