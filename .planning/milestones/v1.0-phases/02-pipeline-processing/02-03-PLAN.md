<objective>
Build `pipeline/embed.py` — Stage 2 of Phase 2. Compute CLIP ViT-B/32 embeddings for every photo in catalog.json (digital and film) and write the resulting N×512 float32 matrix to `pipeline/output/embeddings.npy` in catalog-order.

Purpose: Embeddings are the input to cluster.py — both the per-cluster centroids (computed from digital photos' embeddings) and the KNN assignment for film photos depend on this matrix. Row ordering must align with catalog.json's `embed_index` so cluster.py can pull `embeddings[entry["embed_index"]]` without a separate lookup.

Output: pipeline/embed.py + pipeline/output/embeddings.npy (one-shot, several minutes on CPU for ~1,300 photos).
</objective>
