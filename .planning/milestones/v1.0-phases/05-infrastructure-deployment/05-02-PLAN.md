From site/src/config.js (line 23):
- export const METADATA_URL = import.meta.env.VITE_METADATA_URL || '/metadata.json';

Vite reads any env var prefixed with VITE_ at build time and substitutes it into the bundle.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| developer machine -> Cloudflare API | wrangler deploys signed asset manifest to Workers Static Assets via OAuth credentials. |
| browser -> deployed worker | Untrusted browser fetches static assets (HTML/JS/CSS) from *.workers.dev. |
| browser -> R2 public bucket | Cross-origin fetch from the workers.dev origin to the R2 public URL for metadata.json and images. Trust boundary established in Plan 01 via CORS. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-05 | Tampering | Production bundle | mitigate | Workers Static Assets serves immutable hashed asset bundles; only authenticated wrangler deploy can replace them. site/wrangler.toml contains no secrets. |
| T-05-06 | Information Disclosure | VITE_METADATA_URL baked into bundle | accept | The R2 public URL is intentionally public (Plan 01 established it as the public origin). Baking it into JS exposes nothing that the network tab would not already reveal. |
| T-05-07 | Denial of Service | r2.dev rate limits | accept | Cloudflare docs note r2.dev is rate-limited and "non-production"; for ~100 wedding guests this is not a practical concern (per 05-RESEARCH.md §A2). If hit, mitigation is a custom domain in a follow-up. |
| T-05-08 | Spoofing | Deployed origin | mitigate | Cloudflare provisions workers.dev subdomains with TLS by default; no plaintext HTTP. The CORS policy from Plan 01 allows any origin (origins ["*"]) by design for a read-only public album, so origin-spoofing is not a defense vector. |
| T-05-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs in this plan. wrangler is global v4.92.0 (per 05-RESEARCH.md §Environment Availability). Vite and all site deps were installed in Phase 4 — no new packages introduced. |
</threat_model>
