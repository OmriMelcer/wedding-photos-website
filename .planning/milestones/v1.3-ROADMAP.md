# Milestone v1.3: Lightbox Zoom

**Status:** ✅ SHIPPED 2026-05-23

## Overview

Added pinch-to-zoom (mobile), scroll-wheel zoom (desktop), and drag-to-pan to the lightbox — using the yarl Zoom plugin already bundled inside the installed `yet-another-react-lightbox@^3.32.0`. Zero new npm dependencies. Two-file change: Lightbox.jsx and Lightbox.test.jsx.

## Phases

### Phase 10: Zoom & Pan

**Goal**: Guests can zoom in on any lightbox photo and pan around the zoomed image, on both mobile and desktop
**Depends on**: Phase 9 (lightbox with Download plugin already wired)
**Plans**: 2 plans

Plans:

- [x] 10-01: Wire yarl Zoom plugin (ZOOM-01/02/03)
- [x] 10-02: Manual smoke-test — zoom and pan behavior

**Details:**

The Zoom plugin was imported from `yet-another-react-lightbox/plugins/zoom` and added to the `plugins` prop before the Download plugin (`plugins={[Zoom, Download]}`). Key config choices:

- `maxZoomPixelRatio: 3` — mandatory; default of 1 silently disables zoom on retina/mobile
- `pinchZoomV4: true` — prevents iOS swipe-block after fast pinch-out (bug fixed in yarl v3.27.0)
- `scrollToZoom: true` — safe for modal lightbox; page-scroll bleed issue only affects Inline variant
- `doubleClickMaxStops: 2` — sensible zoom stops for double-tap

Hebrew zoom toolbar labels ("הגדל"/"הקטן") were deferred (out of scope for v1.3 per REQUIREMENTS.md).

TDD: RED assertions added to Lightbox.test.jsx first; GREEN implementation followed. Full suite (53 tests) passed; production build clean (277.55 kB JS).

Smoke-tested on desktop + DevTools mobile simulation: all ZOOM-01/02/03 behaviors confirmed.

## Milestone Summary

**Key Decisions:**

- `plugins={[Zoom, Download]}` order: Zoom before Download so zoom controls appear on outer end of RTL toolbar
- `maxZoomPixelRatio: 3` mandatory: default of 1 silently disables zoom on all retina/mobile devices
- `pinchZoomV4: true` mandatory: prevents iOS swipe-block after fast pinch-out
- Hebrew zoom labels deferred: not requested for this milestone; deferred to future

**Issues Resolved:**

- ZOOM-01: Pinch-to-zoom on mobile (two-finger spread/pinch)
- ZOOM-02: Scroll-wheel zoom on desktop
- ZOOM-03: Drag-to-pan while zoomed in

**Issues Deferred:**

- Hebrew zoom toolbar labels ("הגדל"/"הקטן") — deferred, not a v1.3 requirement

- Zoom level indicator (show current zoom %) — out of scope v1.3
