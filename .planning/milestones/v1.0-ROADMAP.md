# Milestone v1.0: MVP

**Status:** ✅ SHIPPED 2026-05-17
**Phases:** 1–5
**Total Plans:** 16

## Overview

A static wedding photo album website for ~1327 photos from 3 photographers. An offline Python pipeline acquires photos from Google Photos + pic-time, computes CLIP embeddings for film scans, assigns cluster labels, resizes images, and uploads everything to Cloudflare R2. A Vite + React 19 site fetches metadata.json on load and lets guests browse in a Hebrew RTL masonry gallery with photographer and phase filters. Deployed via Cloudflare Workers Static Assets at https://wedding-album.omelcer.workers.dev.

## Milestone Summary

**Key Decisions:**
- `gallery-dl` for Google Photos download (handles auth natively, no selenium required)
- ALL camera EXIF offsets treated as Israel local time — `OffsetTimeOriginal` unreliable on wedding cameras
- CLIP ViT-B/32 CPU-only on M-series Mac (~3m20s for 1327 photos)
- Cloudflare R2 for storage (zero egress) + Workers Static Assets for hosting (free)
- All filtering in-memory in browser; metadata.json fetched once on load (398 KB, under 1 MB constraint)
- GET+HEAD only CORS (no PUT/DELETE) — threat mitigation T-05-01
- Workers Static Assets (`npx wrangler deploy`) over deprecated `wrangler pages deploy`
- `VITE_METADATA_URL` sourced from `pipeline/config.yaml` at build time (single source of truth)
- shadcn nova preset + Heebo font for Hebrew RTL design

**Issues Resolved:**
- Film scan EXIF absence: solved via CLIP KNN assignment against EXIF-anchored centroids
- metadata.json size: 398 KB (well under 1 MB with 1327 photos)
- Workers Static Assets `workers_dev` warning: added explicit `workers_dev = true` to wrangler.toml

**Issues Deferred:**
- Face recognition (FACE-01..04) → v2 scope; schema is forward-compatible
- Orphaned branch with `site/wrangler.toml` (needs cherry-pick c7aa6a2 + 3b578f6 onto main for full reproducibility)

**Technical Debt:**
- REQUIREMENTS.md checkbox states not updated as Phase 1–3 executed (tracking gap, not implementation gap)
- Local `site/dist/` is Phase 4 test build; production bundle exists only on Cloudflare CDN
