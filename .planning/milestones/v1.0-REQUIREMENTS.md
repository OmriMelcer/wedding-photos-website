# Requirements Archive: v1.0 MVP

**Archived:** 2026-05-17
**Milestone:** v1.0 MVP (Phases 1–5)
**Core Value:** Every guest can find and view every photo from the wedding, filtered by who shot it and when it happened — with zero hosting costs and no maintenance burden.

### Photo Acquisition

- [x] **ACQN-01**: Pipeline automatically downloads photos from all 3 Google Photos shared albums

### Pipeline — Processing

- [x] **PIPE-01**: EXIF timestamps extracted from digital photos and normalized to GMT+02:00 (Israel Standard Time)
  _Delivered: Phase 2 Plan 02 — `pipeline/ingest.py`, all camera offsets treated as Israel local time_
- [x] **PIPE-02**: Photographer tag assigned per source folder, mapped to Photographer A, B, or C via config.yaml
  _Delivered: Phase 2 Plan 02 — `pipeline/ingest.py`, photo_id = {label}_{file_stem}_
- [x] **PIPE-03**: CLIP ViT-B/32 embeddings computed for ALL photos (both digital and film); images pre-processed before inference
  _Delivered: Phase 2 Plan 03 — `pipeline/embed.py`, embeddings.npy (1327×512), ~3m20s CPU-only_
- [x] **PIPE-04**: Digital photos assigned to event cluster via EXIF timestamp against config.yaml time windows
  _Delivered: Phase 2 Plan 04 — `pipeline/cluster.py`, time windows: prep/photoshooting/dining/hupa/dancing_
- [x] **PIPE-05**: Per-cluster centroids computed from EXIF-labeled photos; film photos assigned to nearest centroid via KNN
  _Delivered: Phase 2 Plan 04 — `pipeline/cluster.py`, 174 film photos assigned via KNN_
- [x] **PIPE-06**: cluster_confidence score computed for every photo; assignments below threshold flagged for human review
  _Delivered: Phase 2 Plan 04 — `pipeline/cluster.py`, low_confidence.txt output_
- [x] **PIPE-07**: Photos resized to web quality and thumbnails generated per photo for gallery display
  _Delivered: Phase 2 Plan 05 — `pipeline/resize.py`, 1327 web photos (≤2000px) + 1327 thumbnails (≤400px)_

## Out of Scope

| Feature | Reason |
|---------|--------|
| Backend / server | Static-only architecture; no runtime server ever |
| Incremental pipeline | One-shot by design; re-run full pipeline if source photos change |
| Mobile app | Web-first; responsive site covers mobile browsers |
| OAuth / login | Site is public; no authentication needed for guests |
| Real-time updates | No server; updates require re-running the pipeline |
