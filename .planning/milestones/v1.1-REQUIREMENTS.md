## v1.1 Requirements — All Complete

### Pipeline Security

- [x] **SEC-01**: `pipeline/resize.py` strips all EXIF data (GPS coordinates, device identifiers, timestamps) from every web-quality output image before upload — original files in `sources/` are never modified
  - **Outcome:** Implemented via `exif=b""` kwarg on both `.save()` calls in `resize_photo()`. All 6 tests pass. Pillow's `convert("RGB")` would also strip EXIF in practice, but explicit `exif=b""` ensures reliability across Pillow versions.

- [x] **SEC-02**: `pipeline/upload.py` sets `Cache-Control: public, max-age=86400` on `metadata.json` upload so browsers and CDN edges cache it for 24 hours
  - **Outcome:** Implemented via `CacheControl` key in `ExtraArgs` on the metadata.json `upload_file()` call.

- [x] **SEC-03**: `pipeline/upload.py` sets `Cache-Control: public, max-age=31536000, immutable` on all photo and thumbnail uploads so browsers cache images indefinitely
  - **Outcome:** Implemented via `CacheControl` key in `ExtraArgs` on both photo and thumbnail `executor.submit()` calls.

- [x] **SEC-04**: All 1309 photos and thumbnails on R2 regenerated (resize only — no re-embed or re-cluster) with EXIF stripped and re-uploaded with correct cache headers; `metadata.json` cluster assignments unchanged
  - **Outcome:** 1309 photos + 1309 thumbs re-uploaded. Live R2 verification passed all 4 criteria. metadata.json SHA256 unchanged before/after.

### Cloudflare Hardening

- [x] **CF-01**: Cloudflare account has a budget alert at $5/month for R2 operations
  - **Outcome:** Configured in Cloudflare dashboard.

- [x] **CF-02**: Cloudflare account has a budget alert at $5/month for Workers requests
  - **Outcome:** Configured in Cloudflare dashboard.
