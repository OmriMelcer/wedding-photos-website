# Requirements: Wedding Photo Album

**Defined:** 2026-05-23
**Milestone:** v1.3 Lightbox Zoom
**Core Value:** Every guest can find and view every photo from the wedding, filtered by who shot it and when it happened — with zero hosting costs and no maintenance burden.

## v1.3 Requirements

### Zoom

- [ ] **ZOOM-01**: Guest can pinch-to-zoom on lightbox images on mobile (two-finger spread to zoom in, pinch to zoom out)
- [ ] **ZOOM-02**: Guest can use scroll-wheel to zoom in and out on lightbox images on desktop
- [ ] **ZOOM-03**: Guest can drag to pan a zoomed-in lightbox image on any device

## Out of Scope

| Feature | Reason |
|---------|--------|
| Hebrew zoom toolbar labels | Deferred — not requested for this milestone |
| Zoom on gallery thumbnails | By design — zoom is lightbox-only |
| Double-tap to zoom (explicit requirement) | Covered automatically by plugin config; not a separate deliverable |
| Custom zoom controls / UI | yarl plugin handles all UX; no custom UI needed |
